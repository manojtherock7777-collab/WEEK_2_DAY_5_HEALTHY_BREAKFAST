# 🥗 Healthy Breakfast Ideas Generator using LangChain

## 📌 Project Description

This project is a simple AI-powered Healthy Breakfast Ideas Generator built using **Python and LangChain**.

It uses LangChain's `ChatOpenAI` integration with OpenAI's `gpt-4o-mini` model to generate exactly five healthy breakfast ideas.

The project demonstrates how to create structured prompts, invoke an LLM using LangChain, and extract the generated response text using `.content`.
